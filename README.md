# А-Сервис — сайт-визитка + мини-CMS

Простой сайт на PHP + JSON CMS. Никаких зависимостей, никакой сборки.

## Файлы
- `index.php` — публичный сайт
- `admin.php` — админка (пароль в `data/config.php`)
- `data/content.json` — весь контент (создаётся с дефолтом)
- `uploads/` — загруженные картинки

## Локальный запуск
\`\`\`bash
php -S localhost:8000
\`\`\`
- Сайт: http://localhost:8000
- Админка: http://localhost:8000/admin.php
- Пароль по умолчанию: `admin123` (СМЕНИТЕ в `data/config.php`!)

## Деплой на Beget (shared-хостинг)
1. Арендуйте **виртуальный хостинг** Beget (не VPS) — PHP уже включён.
2. В панели выберите PHP 8.0+.
3. Загрузите все файлы через FTP/SFTP в `~/ваш_домен/public_html/`.
4. Дайте права `755` на папку `uploads/` и `data/` (для записи).
5. Откройте `https://вашдомен/admin.php` и войдите.

## Деплой на Beget VPS (Docker-вариант)
Если хочется VPS — просто поставьте nginx + php-fpm, скопируйте файлы, настройте root на папку.

## Что можно редактировать
- Hero-секция (тексты, кнопки, телефон, картинка)
- Преимущества (4 карточки — добавлять/удалять)
- Прайс-лист (категории + позиции — добавлять/удалять)
- О компании (текст, тезисы, цифры)
- Контакты (телефоны, режим, ссылки)
- Футер

## Что НЕ делает CMS
- Не даёт менять CSS/структуру (это в `style.css` и `index.php`)
- Нет пользователей/ролей — один пароль
- Нет истории изменений (но есть `.bak` перед каждой записью)

## Безопасность
- Смените пароль в `data/config.php`
- Файл `content.json` защищён `.htaccess`
- Загрузки проверяются по расширению
- Для продакшена включите HTTPS (Let's Encrypt бесплатно в панели Beget)
